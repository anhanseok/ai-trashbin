# 판단 시간 ↔ 정확도 실험 (2026-11-16)

가설: AI가 더 오래 보고 판단할수록 정확해진다.

## 방법
- 실물 수거함에 쓰레기를 투입구로 떨어뜨리고, 받침판에 닿은 순간부터 0.5초마다 사진과 AI 확률을 기록 ([code/experiment.py](../../code/experiment.py))
- "t초까지 찍힌 사진의 확률 평균"으로 판정했을 때 정확도를 t마다 계산 ([code/analyze_experiment.py](../../code/analyze_experiment.py))
- 모델: 같은 날 찍은 사진 95장으로 만든 첫 모델 ([code/train_quick.py](../../code/train_quick.py))
- 정답은 실험 사진으로 확인 (exp2 9~16번에 딱풀·숟가락이 섞여 있어 일반으로 계산)

| 폴더 | 내용 |
|---|---|
| `exp1_13회_30초` | 물건 13개, 각 30초 기록 |
| `exp2_26회_10초` | 캔 4개×2, 페트·일반 섞인 8회, 일반 10개 = 26회, 각 10초 기록. `result.csv`, 그래프 3장 |
| `slide_result.png`, `slide_table.png` | 두 실험을 합친 39회 발표용 그림 ([make_figures.py](make_figures.py)) |

## 결과 (39회)
| 판단 시간 | 0.5초 | 1초 | 2초 | 3초 | 5초 | 7초 | 10초 |
|---|---|---|---|---|---|---|---|
| 정확도 | 36% | 49% | **54%** | 54% | 51% | 51% | 51% |

- 판정의 90%가 0.7초 안에 굳음 (가장 늦어도 4.7초)
- 품목별 (2초): 캔 91% (10/11), 페트 67% (4/6), 일반 32% (7/22)
- 지금 main.py 규칙(같은 판정 2번 연속)은 exp2에서 정확도 42%, 26회 중 5회는 기록 시간 안에 판단 못 함

## 결론
- 2초까지는 오르고 그 뒤로는 평평 → 판단은 1~2초면 충분. 가설은 2초 이후로는 기각.
- 쓰레기가 멈춘 뒤에는 같은 장면만 보여 새 정보가 없고, 오답 대부분이 학습에 없던 일반쓰레기(케이블, 펜, 과자 상자, 딱풀 등)를 캔으로 본 것 → 정확도는 시간이 아니라 학습 데이터로 올려야 함.
- 물건 수가 적어 신뢰구간이 넓음 (2초: 39~68%).
