# 판단 시간 · 확신도 기준 · 학습 사진 수 실험 (2026-11-18)

## 방법
- 학습에 안 쓴 물건 14개(페트 4, 캔 3, 일반 7)를 2번씩, 28회 투입 ([code/experiment.py](../../code/experiment.py) `28 6`)
- 넣은 순서: 페트 8회 → 캔 6회 → 일반 14회. 정답은 실험 사진으로 확인
- 기록: 받침판에 닿은 순간부터 0.5초마다 사진과 확률, 6초 동안
- 모델: 같은 날 사진 43장을 더해 171장으로 학습한 모델 ([code/train_quick.py](../../code/train_quick.py))
- 기록 폴더: `code/exp/20261118_28회_6초` (중간에 끊긴 두 폴더를 [code/merge_runs.py](../../code/merge_runs.py)로 합침, Git 제외)

## 결과
### 1. 판단 시간 ([code/analyze_experiment.py](../../code/analyze_experiment.py))

|---|---|---|---|---|---|
| 정확도 | 75.0% | 85.7% | **89.3%** | 85.7% | 82.1% |
| 95% 구간 | 57~87 | 69~94 | 73~96 | 69~94 | 64~92 |

- 2초 품목별: 페트 7/8, 캔 4/6, 일반 14/14
- 예전 규칙(같은 판정 2번 연속): 75.0%, 3회는 기록 시간 안에 판단 못 함
- → **판단 시간 2초**로 결정 (`config.DECIDE_SEC`)

## 주의
- 28회라 신뢰구간이 넓음 (2초: 73~96%)
- 실험 도중 지붕(카메라)이 움직여 받침판이 안 보인 3회는 지우고 다시 함
- 받침판에 액체 얼룩이 있으면 빈 받침판을 물건으로 착각함 → 얼룩 있는 빈 사진을 학습에 추가
